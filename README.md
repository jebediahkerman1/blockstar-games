# Blockstar Games website

Responsive static website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — website sections and navigation
- `styles.css` — responsive black-and-lime design
- `script.js` — navigation, search, game catalogue, and sample news

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then press **Save**.
4. Wait a minute or two. The site should appear at https://jebediahkerman1.github.io/blockstar-games/.

The newsroom stories are starter/sample content, not verified official announcements. Edit the `posts` array in `script.js` to replace them. The header uses a built-in text-and-star logo so no image file is required.
